Global Infrastructure

 Google Cloud have two(2) organize infrastructure the Regions and Zones. Regions are not single building because in terms in major cloud computing,it is a large geographic area that isolated zones called Availability Zones packed with computer servers where the Google Cloud is hosted. Availability Zones are not the same as the Region, Zones are isolated locations within a Region. This structure helps organizations improve application availability, reliability, and performance.
