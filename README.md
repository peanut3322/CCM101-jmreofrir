# Laboratory 01 – Welcome to the Cloud

## Mission Overview
This laboratory introduces cloud-based Linux environments using KillerCoda. The goal is to practice basic Linux system administration, gather system information, organize a workspace, and establish a professional GitHub portfolio.

## Objectives
- Launch and use a cloud Linux playground (KillerCoda Ubuntu)
- Create a new user with Bash shell, home directory, and sudo privileges
- Investigate the Linux environment (distribution, kernel, CPU, memory, disk)
- Create a structured workspace with folders and Markdown files
- Build a public GitHub repository with the required folder structure
- Document all activities and upload evidence (screenshots)

## Activities Performed
1. Launched Ubuntu playground on KillerCoda
2. Created a new sudo user and logged into the account
3. Collected system information (OS, kernel, CPU, memory, disk space)
4. Created the folder structure (Documents, Projects, Notes, Scripts)
5. Wrote about-me.md and system-information.md
6. Created the public GitHub repository CCM101-rjmeim
7. Organized all files and screenshots inside the Laboratory-01 folder
8. Documented the mission in this README

## Linux Commands Used
- `sudo adduser` / `sudo usermod -aG sudo` / `su -`
- `whoami`, `pwd`, `hostname`
- `cat /etc/os-release`, `uname -r`, `lscpu`, `free -h`, `df -h`
- `mkdir -p`, `ls -la`, `nano` / `cat`
- `git clone`, `git add`, `git commit`, `git push`

## Skills Learned
- Accessing and navigating a cloud-based Linux environment
- User account creation and privilege management
- Gathering and interpreting basic system information
- Creating and organizing directories and Markdown documentation
- Setting up and structuring a professional GitHub portfolio
- Using Git for version control and evidence submission
